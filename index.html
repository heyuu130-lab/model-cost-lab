    DATA NOTES
    透明地说明能算什么。
    数据按供应商官方 API 定价页面整理。每条记录带有模型 ID、货币、计量单位、来源 URL、核验日期和备注。
    DeepSeek 价格按官方页面的非高峰、缓存未命中价格计算；官方页面说明高峰时段价格更高。OpenAI 和 Anthropic 的记录在当前版本保留来源，但在无法从官方页面稳定确认具体价格前不会参与计算。
